Process network bar — Tx grows left, Rx grows right, from the center

The new Network-page column. Same box as the Disks usage bars (160 × 12 px, trough #1b1b1b, §5b — fixed, only the fill moves). Scale: each side is normalized to the busiest process on ITS side, so a download-heavy app fills only the right (Rx) half and an upload-heavy app only the left (Tx) half. Restricted processes (Yama) draw the center line alone with "—" rates.
Tx — transmitted (grows left ←) Rx — received (grows right →) · center line = zero · classic network-illustration color code (blue in / yellow-out, as in mockup Q's legend)
